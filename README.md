## What's here

- index.html: the front page, with bio and list of articles
- style.css: fonts, colors and layout for every page
- published/articles/: one file per article
- images/: photos used on the site

## Publishing a new article

1. Add the article file to published/articles (Add file, Upload files, Commit changes).
2. Add a link to it in index.html.
3. Wait a minute or two, then refresh the site.

Every change is saved in the history (the Commits link), so anything can be undone.
